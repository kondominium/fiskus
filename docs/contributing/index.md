# Contributing

> **Build notice.** This section is for people and agents building fiskus. It describes how the code, docs, and guide are changed. A build of fiskus is not a tax assessment, must not be used to file a return, and is not official software of the Federal Ministry of Finance (Bundesministerium der Finanzen, BMF) or ELSTER. Nothing here is tax advice.

Start with [Workflow](workflow.md), then read the page for the part you are touching. Agents start with `.agents/AGENTS.md`.

| Page | Read it for |
|---|---|
| [Workflow](workflow.md) | Branches, rebasing, commits, handover |
| [Releasing](releasing.md) | Cutting a release, version policy, recovery |
| [Code](code.md) | Gates, code rules, style, examples |
| [Tests](tests.md) | Which test layer proves a claim, benchmarks |
| [Guide](guide.md) | Changing `docs/guides/`, its charts and icons |
| [Language](language.md) | Writing docs and doc comments |
| [Design](design.md) | The wordmark, colors, typography |

For how fiskus is built, tested and measured, see [Build](../internal/build/README.md), [Testing](../internal/testing/README.md) and [Benchmarks](../internal/benchmarks.md). Those pages describe the model. These pages say what to do.
