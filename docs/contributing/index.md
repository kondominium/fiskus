# Contributing

> **Build notice.** This section is for people and agents building fiskus. It describes how the code, docs, and guide are changed. A build of fiskus is not a tax assessment, must not be used to file a return, and is not official BMF or ELSTER software. Nothing here is tax advice.

Start with the rules that apply to every change, then read the page for the part you are touching.

- [Code gates and rules](code.md): the gates a change must pass, the code rules, style, tests, and commit messages.
- [Language](language.md): how we write docs and doc comments, German aliases, citations, and the glossary.
- [Guide](guide.md): the rules for the guide in `docs/guide/`, its charts, and the tokens behind them. Includes instructions for agents.
- [Design](design.md): the fiskus wordmark, color, typography, and usage rules.
